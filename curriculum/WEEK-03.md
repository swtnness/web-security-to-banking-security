# Week 3 — HTML, JavaScript and Python foundations

**Prerequisites:** Week 2: navigate to a folder and inspect a file.

**Time:** six 60-minute sessions; Day 7 is rest or catch-up. For each session, read for about 15 minutes, practice for 35 and write evidence for 10. Split a difficult session over two days if necessary.

## Understand

HTML describes page structure. JavaScript changes browser behavior. Python will implement server-side decisions later. A local HTML form is not an authenticated application, and changing browser values does not grant server permissions.

## Do these sessions in order

1. **Day 1.** Complete parts A and B of [Lab 02](../labs/LAB-02-local-web.md): save the page, change its heading and run a local server. Explain file:// versus http://127.0.0.1.

2. **Day 2.** Inspect the form's input, button and output in Developer Tools. Try empty input and `<b>Alice</b>`. Explain why the angle brackets remain visible with textContent.

3. **Day 3.** Complete Lab 02 part C. Predict the Python output before running it. Trace variables, a list, a loop, a dictionary, an if statement and a function.

4. **Day 4.** Change the Python example so only the owner can read a record. Try Alice, Bob and a missing actor. Print a separate expected and actual result for each case.

5. **Day 5.** Read the cookie and session entries in the glossary. Draw browser cookie → request → server session lookup → user. Explain why an account number in JavaScript is not proof of ownership.

6. **Day 6.** Recreate a small page and an ownership function without copying. Keep one mistake and its correction in your notes. Save the code in your exercise folder and a short explanation in progress.

## Evidence

Save `progress/week-03.md` with the local URL, Python outputs, a session diagram and links to your own exercise files.

## Checkpoint

Can you explain every line of the ownership function and show a non-owner being denied? Repeat the Python exercise before starting security labs if this is unclear.

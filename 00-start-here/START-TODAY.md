# Start today

**Today's goal:** explain one browser request. You need a browser, a text editor and about 60 minutes. You do not need Kali Linux, a paid course or a payment-provider account.

1. **5 minutes — make a place for evidence.** Open [the daily journal](../progress/DAILY-LOG.md). Copy its entry template and write today's date. Use English for technical terms; explain difficult ideas in Spanish first if that helps.
2. **15 minutes — read.** Open [MDN: how the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works). Find the words browser, server, DNS, HTTP and response. Write one short definition for each.
3. **25 minutes — observe.** Follow [Lab 01](../labs/LAB-01-http.md). Observe a normal page load; no scans or modified requests to public websites.
4. **10 minutes — explain.** Write five sentences tracing the request. Record the method, status and two response headers you actually saw. If the request failed, record the error instead.
5. **5 minutes — close the loop.** Write one question and your next action. Update the Day 1 row in [the tracker](../progress/PROGRESS.md).

**Done today:** you can point to a request and its response and say which one the browser sent.

Next: [Day 2 in the first-week plan](../curriculum/WEEK-01.md). The full path is in [the roadmap](../curriculum/ROADMAP.md). Dates are flexible; Day 1 means your actual first session.

If you only have 25 minutes, do steps 1–3 today and the explanation tomorrow. If you get stuck, record the exact step, expected result, actual result and one thing you tried. Avoid reinstalling everything.

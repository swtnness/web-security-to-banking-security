# Small glossary

Use examples from your own lab notes. You do not need to memorize the entire list on Day 1.

| Term | Meaning in this course |
|---|---|
| Client / browser | Software that asks a server for a resource and displays a result |
| Server | Software that receives requests and sends responses |
| URL | An address with a scheme, host, optional port, path and possibly query/fragment |
| DNS | A system used to look up records such as a hostname's IP addresses |
| IP address / port | A network address / a numbered service endpoint |
| TCP | A reliable transport used by HTTP/1.1 and HTTP/2 |
| TLS / HTTPS | Protection of a connection / HTTP carried over a secure connection; HTTP/3 uses QUIC with TLS |
| Request / response | A client's message / the server's answer |
| Header / body | Message metadata / content |
| GET / POST | Request a representation / submit data for processing; neither is an authorization check |
| 200 / 302 | Success / temporary redirect |
| 401 / 403 / 404 | Missing or invalid authentication / forbidden / not found |
| Cookie | Browser-managed data sent according to scope and cookie rules |
| Session | The application's way of tracking a signed-in interaction |
| Authentication | Establishing who is acting |
| Authorization | Deciding whether that actor may do this action to this object |
| Trust boundary | Where data crosses into a component with different trust or privileges |
| Validation | Checking data against allowed formats, ranges and business rules |
| Encoding | Representing output safely for its destination context |
| SQL / parameter | A database query language / a separate value supplied to a query |
| ORM | A framework's interface for querying and updating stored objects |
| CSRF | An unwanted request made using a browser's automatically attached credentials |
| XSS | Untrusted content being interpreted as executable browser code |
| IDOR / BOLA | Missing authorization for an object referenced by an identifier |
| API | An interface for software to request data or actions |
| JSON | A text format for objects, arrays and basic values |
| MFA / step-up | Multiple factor types / stronger or renewed verification for a sensitive action |
| Hash / encryption | A one-way digest / reversible protection using a key; passwords need a password-hashing scheme |
| Least privilege | Grant only the permissions required for the job |
| Invariant | A rule that must remain true after every operation |
| Atomicity | Related changes succeed together or have no committed effect |
| Race condition | An outcome depends on the timing of overlapping operations |
| Idempotency | Repeating the same intended operation has no additional effect |
| Replay | Resubmitting an earlier message or authorization |
| Ledger / reconciliation | A record of financial entries / comparing independent records and investigating differences |
| PSP / tokenization | Payment service provider / replacement of sensitive data by a controlled reference |
| Webhook | A service-to-service event notification |
| False positive | An alert that does not represent the suspected problem |
| Residual risk | Risk that remains after selected controls are applied |

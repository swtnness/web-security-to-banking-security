# Official sources and when to use them

Prepared 2026-10-11. These are reading references, not completion evidence. The curriculum's schedule, exercises and rubric are original teaching material. External lab pages remain their publishers' material; follow links for the full lessons.

## Foundations

- [MDN: how the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works) — Week 1.
- [MDN: HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — requests, responses and browser/server roles.
- [MDN getting started](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started) — HTML and browser foundations.
- [Git book](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control) — Week 2; read the beginner sections.
- [Python tutorial](https://docs.python.org/3/tutorial/) — Week 3; focus on basic values, functions and data structures.
- [Python local HTTP server](https://docs.python.org/3/library/http.server.html) — development-only local serving.

## Security practice and defense

- [PortSwigger learning paths](https://portswigger.net/web-security/learning-paths) — hosted practice.
- [SQL training lab](https://portswigger.net/web-security/sql-injection/lab-retrieve-hidden-data), [XSS training lab](https://portswigger.net/web-security/cross-site-scripting/reflected/lab-html-context-nothing-encoded), [access-control training lab](https://portswigger.net/web-security/access-control/lab-unprotected-admin-functionality) — the three assigned hosted exercises.
- [OWASP Top 10](https://owasp.org/Top10/) — awareness and risk categories; not a complete verification checklist.
- [OWASP ASVS](https://owasp.org/projects/asvs) — testable requirements; record the consulted version.
- [SQL injection prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html).
- [XSS prevention](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html).
- [CSRF prevention](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html).
- [Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) and [authorization](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html).
- [Logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html).

## Financial-security study

- [OWASP transaction authorization](https://cheatsheetseries.owasp.org/cheatsheets/Transaction_Authorization_Cheat_Sheet.html) — Week 13 principles.
- [Stripe idempotent requests](https://docs.stripe.com/api/idempotent_requests) — provider-specific retry behavior.
- [Stripe webhooks](https://docs.stripe.com/webhooks) — signature verification, duplicates and delivery behavior.
- [PCI SSC: PCI DSS](https://www.pcisecuritystandards.org/standards/pci-dss/) — payment-data security awareness.

## Repository repair

- [GitHub: adding files](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).
- [GitHub: deleting files](https://docs.github.com/en/repositories/working-with-files/managing-files/deleting-files-in-a-repository).

If a resource moves, search the publisher's own site by title. Record access problems instead of inventing a lab result. You do not need to read every source before starting Week 1.

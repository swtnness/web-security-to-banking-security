# Evidence folder

Put reviewed screenshots or text output here as you study. No evidence has been created on your behalf.

Use a descriptive filename such as `week-01-http-headers.png`. A small text transcript is often clearer than a screenshot. Link a new file from your report using its relative path.

Do not store raw HAR files, proxy projects, live session cookies, authorization headers, reset links, payment details or personal data. The .gitignore is only a convenience; always inspect what you upload.

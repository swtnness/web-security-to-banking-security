# Web Security → Banking Security
### Vannesa's learning repository

Learn how websites work, how common security failures happen, and how to protect a small application before studying simulated money movement.

**Start here: [your first study session](00-start-here/START-TODAY.md).** No previous programming or security experience is assumed. The core path takes about **5–7 hours a week for 16 weeks**. Repeat a week when its checkpoint is still unclear.

## The learning path

| Stage | Weeks | What you will make |
|---|---|---|
| Understand the web | 1–3 | HTTP field notes, a local page, small Python exercises |
| Understand security failures | 4–7 | A threat model and lab reports that explain prevention |
| Protect a website | 8–11 | A local Django notes app with login, ownership checks and tests |
| Protect simulated money movement | 12–16 | A mock-bank threat model, transfer tests, payment design and assessment |

Every week has ordered sessions, specific practice, an evidence requirement and a checkpoint. Open the [complete 16-week curriculum](curriculum/ROADMAP.md).

## How to study

Use five 60-minute sessions and one 60-minute review each week. Spend about 15 minutes reading, 35 minutes doing the task and 10 minutes explaining what happened. Day 7 is for rest or catching up. Week 1 has a gentler, fully written daily plan.

For each security issue, answer: **What went wrong? Who could be affected? Where should the protection live? What test would show it works?** Completing a lab without explaining the defense is unfinished work.

All progress boxes start empty. Suggested filenames are work you will create; they are not claims that you have completed the course.

## Practice boundaries

Use your own local lab and the specific training instance launched by Web Security Academy. Use fake users, balances and payment events. Do not test real banks, payment websites or unrelated public services. Keep credentials, cookies, payment data and personal details out of this public repository. Read the [lab rules](SECURITY.md).

This is a learning portfolio. The mock-bank work is a simulation and design assessment, not a production banking platform or certification.
